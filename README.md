## Stabilizing EM-Based Quantification under Label Shift

Experiments done for this research.

1. Create a conda environment: `conda create -n emq python=3.10.12`
2. Activate it: `conda activate emq`
3. Install pip: `conda install pip`
4. Install the dependencies with `pip install -r requirements.txt`.
5. Run `python run_experiments_v2.py`.
6. Analyze the results with the notebook `formatresults.ipynb`.
